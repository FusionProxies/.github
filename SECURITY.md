# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

- Email support@fusionproxy.net with the subject **SECURITY**
- Or use **Report a vulnerability** on the repository's Security tab, where GitHub offers it

Include the repository, the version or commit, what an attacker could do, and the steps to reproduce. We will confirm that we received the report and keep you updated until it is fixed.

This covers the code in the FusionProxies repositories. For the Fusion Proxy service itself (website, dashboard, proxy gateways), use the same address.

## Credentials

If you committed proxy credentials to a public repository by mistake, change the password in the dashboard right away. Removing the commit is not enough, because public repositories are copied by bots within minutes.
